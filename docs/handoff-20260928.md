## Live findings (Cubase 15.0.10, MIDI Remote API 1.2)

- Calling `HostObject.getUniqueIDString`/`getRuntimeID` from a MIDI callback destabilizes Cubase. Identities come only from DirectAccess (`VST Mixer` children); roots need `update` before reads.
- File dialogs: the Open and MIDI-import dialogs accept `WM_SETTEXT` + IDOK. **Save As ignores `WM_SETTEXT`**, so the path is typed into the focused field and read back. Cubase's own dialogs (Add Track, Export, question boxes) expose no controls.
- Record, cycle and metronome need latched presses, released on idle. MIDI-track volume/pan are 7-bit, so they are verified within half a step. Cubase does not reopen the file of the already active project.
- MIDI Remote unique IDs are only session-scoped (the same string reappears after a restart); handles also carry driver/project epochs.
